# Freedom Monitor — Казахстан

Ретроспективная траектория новостного поля Казахстана (01.2022 → 07.2026) по осям,
вдохновлённым Эрихом Фроммом: «давление среды ↔ освобождение» и «пространство возможностей»,
плюс солидарность, эмоциональный тон, механизмы бегства и давление на прессу.

**Открыть результат:** `dashboard.html` (self-contained, работает офлайн).

## Команды

```powershell
.\.venv\Scripts\python.exe run.py --rebuild-dashboard   # пересборка дашборда из data/
.\.venv\Scripts\python.exe run.py --validate            # только валидация событий
.\.venv\Scripts\python.exe run.py --market              # дотянуть курс USD/KZT из API НБ РК
.\.venv\Scripts\python.exe -m pytest tests/ -q          # тесты агрегации, пере-скоринга, надёжности
```

Пере-скоринг и проверка надёжности:

```powershell
.\.venv\Scripts\python.exe run.py --rescore data\patches\ФАЙЛ.jsonl --out data\events_vN.jsonl --version N
.\.venv\Scripts\python.exe run.py --reliability data\events_v1.1.jsonl data\reliability\pass_b.jsonl
```

| `data/events_v1.1.jsonl` | пере-скоринг: теги §3, демаркация осей §1.2/§1.3 |

## Методология

Кодбук — `METHODOLOGY.md`: шкалы −3…+3, значимость 1–3, казахстанская таксономия якорей,
поведенческий кодбук тегов, формулы Flow/Level, предрегистрированная квадрантная гипотеза,
рамка «температура новостного поля, не общество».

Три отчёта, которые надо читать вместе с кодбуком — в них сказано, чем измеренные
числа **не** являются:

| Отчёт | О чём |
|---|---|
| [RELIABILITY.md](RELIABILITY.md) | согласие двух кодировщиков; независимая модель дала 50% по оси тона и 65% по значимости |
| [SENSITIVITY.md](SENSITIVITY.md) | устойчивость кривой к параметрам: форма держится, величина — нет; две трети кривой solidarity — инерция |
| [HYPOTHESIS.md](HYPOTHESIS.md) | проверяемость H1: на 12 месяцах тест не работает в принципе, нужно от 48 |

Диагностика (`--validate`) показывает реальную базу измерения отдельно от числа событий:
из 280 записей хотя бы одну ось задевают 199, а ось solidarity держится на 25 событиях.
